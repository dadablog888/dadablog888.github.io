## 수집과 검토

- 월별 collect → manifest 확인 → 신규 원문 텍스트 전체 검토 → 소개문 작성 → apply 순서로 처리했다. 원문 전체는 무시된 `.cache/blog-sync/`에만 보관한다.
- SmartEditor 2와 구형 SmartEditor 3 본문 영역 및 구형 발행 시각·카테고리 표기를 지원하도록 파서를 보완했다. 요청한 글 영역만 읽고 제목·출처 도구·다른 글·댓글 메뉴가 본문에 섞이지 않는 회귀 테스트를 추가했다.
- 원문 제목·카테고리·분 단위 KST 발행 시각·출처 해시를 보존했다. 오래된 방송과 책의 정치·역사·경제·건강 관련 주장은 해당 자료의 견해로 구분했다.
- 이미지, 가사, 원문 전체를 재게시하지 않았다. 첨부 PDF·카페 자료·외부 영상의 내부 내용은 확인한 본문을 넘어 추정하지 않았다. 짧은 글은 관찰되는 텍스트 범위로만 소개했다.
- 비공개·삭제·차단 글은 공개 목록만으로 전체 존재 여부를 알 수 없다. 이 보고서의 전체 범위는 확인 시점의 공개 글 기준이다.
