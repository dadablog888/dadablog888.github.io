## 검토 내용과 한계

21건의 정규화된 원문 텍스트를 모두 읽고 각각 소개문을 작성했습니다. 통대 생활과 휴학, 생활용품 후기, 방송·잡지·관광책자를 이용한 중국어 학습, 사진 문구 번역, 드라마와 고전 읽기 기록입니다. 새 주제를 추가하지 않고 기존 내용 분류를 사용했습니다.

12월 손자병법 1~6편은 고전 원문과 작성자의 한국어 풀이를 소개합니다. 미월전과 삼국지 등은 드라마·강의·개인 독서 메모의 맥락을 구분했고, 역사·정치 해석을 검증된 사실이나 전체 집단의 견해로 단정하지 않았습니다. 과거 가격과 정책, 운영·개발 정보는 당시 기록으로 한정했습니다. 제품 후기는 개인 사용감이며 성분·건강 효능을 검증한 자료로 소개하지 않았습니다.

사진·영상 자체와 이미지 속 문자는 검증하지 않았습니다. 어휘 목록의 개별 대응을 모두 교정하거나 외부 사실 검증을 수행한 작업은 아닙니다. 가사·이미지·원문 전문을 공개 문서에 복제하지 않았습니다. 전문은 Git에서 제외된 `.cache/blog-sync/2020-MM/sources/`에만 보관합니다.
