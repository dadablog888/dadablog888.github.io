# 2019년 및 이전 공개 글 정리

요청 범위: 공개 목록에서 확인한 가장 오래된 2015-02부터 2019-12까지 월별 처리(2015년 1월도 빈 기간 확인). 최초 목록 조사: 209건, 마지막 페이지 28, 전체 공개 814건.

1. 기존 소개 605건의 해시를 보존한다.
2. 월별 collect → manifest → 신규/변경 원문 전체 검토 → 독립적인 소개문 작성 → apply를 수행한다. 빈 월도 확인한다.
3. 오래된 편집기 본문 파싱 문제가 있으면 실제 HTML을 확인한 뒤 최소 수정·테스트한다. 불완전 수집은 완료로 표시하지 않는다.
4. 전체 build/check, 대표 재수집 및 소개 수정일 불변 확인, 로컬 미리보기.
5. 형제 루트 Pages 저장소에 홈 복사·검사. 커밋/푸시/배포 없음.
6. 연도별·월별 결과와 제한을 docs에 기록한다.

## 완료

- 2015~2019년 60개월 확인, 공개 대상 209건 모두 신규 반영. 기존 605건 보존, 전체 814건.
- 구형 편집기 수집 보완 및 7개 회귀 테스트 통과. build/check 통과.
- 2015-02·2019-04 재수집에서 10건 동일, 전체 소개문 내용·수정 시각 불변.
- 대표 로컬 화면과 HTTP 응답 확인, 루트 홈 복사 및 --check 통과.
- 상세 결과: `docs/period-update-through-2019.md`. 커밋·푸시·배포 없음.
